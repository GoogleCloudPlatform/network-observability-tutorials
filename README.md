# Cloud Network Observability Tutorials

This repository contains a collection of tutorials and sample workflows designed to help you observe, diagnose, and optimize your Google Cloud Networking resources.

These tutorials leverage specialized, open-source agentic skills to allow you to trigger complex diagnostic and analysis workflows with minimal effort.

## Before you begin

1.  You'll need access to a Google Cloud Platform (GCP) account and project. [Sign up for a free GCP trial account](https://console.cloud.google.com/freetrial).
2.  Ensure you have the necessary permissions to access the networking resources in your project (e.g., VPC, Flow Logs).
